# apps/storefront — LEGACY, not the product surface

This app is legacy demo code carried over from the source copy. It is **not**
the product surface for Muse Shopping Index, and it is not a storefront for
the product: Muse Shopping Index is a Muse feature. The product surface is
the Muse feature panel (`apps/demo/src/muse-feature-panel.ts`), mounted by a
Muse host inside a Muse window/surface, and the live judged demo is
`docs/demo/` on GitHub Pages.

This folder is kept, isolated and header-marked, so the legacy app still
builds and its CI-listed tests still pass. Do not build new product flows
here, and do not present anything in this folder as the product.
